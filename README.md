# 场景交互及物品栏系统

**版本 1.0.7** · 作者：池水三两升 · SDK：`>=1.9.9`

用内置编辑器制作多场景探索、点击拾取与物品合成，在剧本中直接调用。

![场景编辑器](docs/images/scene-editor.jpg)

## 功能

- 场景底图、交互点、转场与悬停效果。
- 图片素材库：导入、分类、搜索、查看引用、回收站恢复。
- 交互点显示条件与动作链，支持编辑变量 `=`、`+=`、`-=`、`*=`、`/=`。
- 物品库、合成配方、全屏背包与可关闭的快捷栏 HUD。
- Ctrl + 滚轮缩放画布，中键平移，交互点框体贴合图片尺寸。
- 玩家库存与场景进度随存档保存，兼容旧版图片资源引用。

## 快速上手

1. 在 Studio **个性化 → 本扩展 → 场景编辑器** 打开编辑器。
2. **素材库 → 选择文件夹** 连接本扩展目录，选择类别并导入图片。
3. 新建场景、设置底图；新建物品，再给交互点添加 **给予物品** 动作。
4. 在剧本加入 **调用扩展方法 → 场景交互 → 打开场景交互（阻塞）**，填写场景 ID 或名称。
5. 使用 **剧本 Preview** 试玩，点击拾取、打开背包，退出场景后继续剧情。

详细操作见 **[作者图文教程](docs/author-tutorial.md)**。

## 使用提示

- 不需要快捷栏：在 **UI → 快捷栏 HUD** 关闭 **自动显示背包快捷栏**，同时停用物品飞入动画。
- 顶栏 **运行预览** 使用当前选中场景和独立沙箱；完整剧情与存档流程请用剧本 Preview。
- 素材库图片与自动清单保存在扩展 `assets/materials/`；迁移或交付时一起携带。旧工程资源路径和图片 URL 可继续使用。
- 源码关联模式导入素材后，Studio 可能刷新插件界面；返回素材库继续操作，成功导入的图片仍保留。
